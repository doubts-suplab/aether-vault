Capability

Five Facets of Knowledge

Aether Vault owns the ecosystem's Knowledge capability exclusively — ingesting enterprise content and turning it into retrievable, structured, always-fresh knowledge.

Indexing

Document Ingestion

Chunk, embed (384-dim), and store documents — from inline text or a source URI, idempotently, so re-indexing never leaves stale chunks.

Connectors

Source Ingestion

Pull from file: (allowed-root confined), http(s):, or s3: sources through a default-deny registry — freshness-aware, so an unchanged source is never re-embedded.

Search

Vector Search

Cosine-distance semantic retrieval over pgvector, scoped strictly to a single collection.

RAG

Retrieval Pipeline

Embed a query, retrieve nearest chunks, assemble a length-bounded context for an agent's prompt.

Graph

Knowledge Graph

Named-entity nodes with mention salience and typed, confidence-weighted relation edges.

Freshness

Re-index Sweep

A scheduled sweep flags indexed documents past their re-index interval as stale — marks, never deletes.

Ingest → Retrieve

From Document to Prompt Context

A document is chunked and embedded on ingest; a query is embedded and matched against those chunks, then assembled into a bounded context — retrieval never leaves the collection.

INGEST

Inline text or a source connector; register, compute checksum.

→
CHUNK

→
EMBED

Architecture

Four Maven Modules

Strict inward dependency: vault-api → vault-engine → vault-domain. The domain is pure Java 21 — no framework coupling.

vault-domain

Domain & Ports

KnowledgeDocument, DocumentChunk, KnowledgeScope, RagContext, KnowledgeEntity, EntityRelation + port interfaces. No Spring.

vault-engine

Adapters & Services

pgvector chunk store, Ollama embedding, text chunker, ingestion, RAG pipeline, knowledge-graph store, freshness sweep.

vault-api

REST API · Port 8084

Spring Boot app, controllers, Flyway migrations, scheduled freshness, Micrometer metrics.

vault-infra

Infrastructure

Docker Compose, Kubernetes manifests, standalone migration copies. No Java sources.
